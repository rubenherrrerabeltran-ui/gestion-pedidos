# Sistema de Gestión de Pedidos — módulo front-end

**SENA — ANALISIS Y DESARROLLO DE SOFTWARE. (3186691)**  
**Evidencia:** GA7-220501096-AA4-EV03  
**Aprendiz:** Rubén Darío Herrera Beltrán

Módulo demostrativo en **React 18** con navegación entre panel, usuarios, productos y pedidos. Incluye formularios, validaciones, comentarios en el código, búsqueda y persistencia de datos de demostración con `localStorage`.

## Ejecución

Abra `index.html` en un navegador con acceso a internet. React y ReactDOM se cargan desde un CDN. Los datos son locales al navegador; **no hay conexión a una API ni a MySQL**.
